CORE CONCEPTS

Build a better mental model

Beginner + advanced notes
01What makes a password strong?

A strong password is hard to predict, long enough, and unique to one account. Randomness and length are more reliable than cosmetic complexity.

Advanced: Attackers use ranked guesses, leaked credentials, and patterns before they try every possible string.
02Why does length matter?

Each additional independent random character expands the possible search space. A longer passphrase can be both memorable and difficult to guess.

Advanced: Length multiplies the space only when characters are chosen unpredictably; repeated or familiar words reduce that benefit.
03What is entropy?

Entropy is a way to describe uncertainty. More possible equally likely choices mean more entropy, but human choices are rarely equally likely.

Advanced: This app shows a character-set ceiling and a rough penalty-adjusted estimate. Neither is a measured property of a particular attacker.
04Brute force vs. dictionary attacks

Brute force checks combinations. Dictionary-style attacks try common passwords, words, names, dates, and predictable variations first.

Advanced: A good password hash slows offline guesses; a website’s rate limits and MFA can slow online attacks.
05Why is password reuse dangerous?

A password exposed at one site may be tried on other sites. Unique credentials keep one breach from unlocking several accounts.

Advanced: Credential stuffing automates attempts using username/password pairs from earlier breaches.
06Password managers and MFA

A password manager helps create and remember unique random credentials. Multi-factor authentication adds another proof beyond the password.

Advanced: Protect the manager with a strong master credential and recovery plan; phishing-resistant MFA is preferable where offered.
07What is a passkey?

A passkey uses a device-held cryptographic key instead of a shared password. It can make phishing much harder because it is tied to the real service.

Advanced: Passkeys use public-key cryptography; account recovery and device sync are still important to understand.
08Why can complexity be misleading?

A familiar word with a predictable number or symbol may look complex but remain easy to guess. Length and unpredictable choice matter more.

Advanced: Attackers model common transformations such as capitalization, substitutions, suffix years, and keyboard walks.

YOUR INPUT STAYS YOURS

Privacy & safety

SecureCheck is designed to make password analysis useful without collecting the password.

LOCAL-FIRST BY DEFAULT

Nothing you type is sent to a server.

All analysis happens in JavaScript inside this page. This app does not make network requests or include third-party scripts, analytics, or tracking.

What SecureCheck does

  • Analyze locallyPassword checks run in your browser tab only.
  • Generate securelyNew credentials use the browser’s cryptographic random number generator.
  • Export safelyTXT and JSON reports contain analysis details but never the password.
  • Keep optional history minimalWhen enabled, statistics are held in memory in this tab and disappear when it closes.
  • Auto-hide revealsWhen enabled, visible analyzer and comparison fields hide after 30 seconds; all revealed fields hide when the tab loses focus.
  • Clear on navigationAnalyzer and comparison values clear when you leave their page or reset them.

What is retained

LOCAL STORAGE

Theme, accent, density, auto-hide, motion, sound, panel visibility, history preference, and default pace preferences.

TAB MEMORY

Optional score, length, entropy, category counts, and finding labels. No password or password fragment.

NEVER

Password text in browser storage, passwords in URLs, analytics events, or network submissions.

Use estimates as education, not as a security guarantee.

Guessing times depend on unknown attacker behavior, storage algorithms, hardware, account controls, and password reuse. SecureCheck performs only mathematical estimates and never attempts to guess or crack a password.
